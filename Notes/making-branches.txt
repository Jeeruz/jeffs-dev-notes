GIT BRANCH NAMING CONVENTION


Format: type/short-description

COMMON TYPES

feature/  : New features or UI components
fix/      : Bug fixes
refactor/ : Code improvements or restructuring
chore/    : Maintenance, dependencies, config updates
docs/     : Documentation updates

RULES

• Use lowercase only
• Use hyphens (-) to separate words (kebab-case)
• Keep it brief, clear, and descriptive

QUICK EXAMPLES

feature/markdown-editor
feature/user-notes-list
fix/routing-page-flash
fix/auth-token-refresh
refactor/state-management
chore/update-nuget-packages
docs/update-readme
